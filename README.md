# I'm Sorry, My Love ❤️

## Update your existing GitHub Pages site
1. Download and unzip this folder.
2. In your existing GitHub repository, upload `index.html`, `background-video.mp4`, and `photo.jpg` to the repository root.
3. Choose **Commit changes**.
4. Wait a minute or two, then refresh your GitHub Pages website.

The MP4 video is set to autoplay, stay muted, and loop. The overlay and message card are more transparent so the video is easier to see.

Note: the supplied video is only about 1.5 seconds long, so it will repeat frequently.
